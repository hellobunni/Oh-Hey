You are helping build a personal website called oh-hey-lynae using TanStack Start, React, Tailwind CSS, and shadcn/ui (New York style, Zinc base).

File structure lives in src/:
- src/routes/ for pages (__root.tsx is the root layout, index.tsx is homepage)
- src/components/ for custom components
- src/components/ui/ for shadcn components (never manually edit these)
- src/lib/utils.ts for utilities

Design is dark, bold, and expressive. Base is zinc-950 background, zinc-100 text.
Domain accent colors:
- Tech: #3b82f6
- Fitness: #10b981
- Creative: #f97316
- Nerd Stuff: #8b5cf6

Always use Tailwind utility classes. Never write inline styles.
Always use shadcn primitives (Button, Card, Input, Badge) when available.
Components should be typed with TypeScript. No any types.
Keep components small and single-purpose.
